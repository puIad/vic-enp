# Inspiration

The owner's references for the 3D world, the assets and the motion. They decide the concept in
[experience.md](experience.md#the-3d-world-three-concepts) and the answers to scroll-craft's questions 1, 5, 6
and 7.

## How to add one

Add a row below. Screenshots or screen recordings go in `docs/inspiration/` (create it), named after the row
number, for example `03-hero.png` or `03-scroll.mp4`. A link alone is fine when the thing is a live site.

For each reference, say **what to take** from it. "I like it" can't be built; "the way the points follow the
cursor with a delay" can.

Scroll-craft's advice holds: references from any medium (a film, an album cover, a game, a stage show, a poster)
are worth more than websites, because naming sites is how a page ends up looking like an existing site.

## Rules for using references

- A reference is something to learn from, never something to copy. No assets, models, shaders or code from a
  reference site go into the build unless their licence allows it and the source is noted in
  [assets.md](assets.md).
- Each reference that changes the plan gets a line in [decisions.md](decisions.md).
